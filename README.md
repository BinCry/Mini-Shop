**Mini-Shop** là một nền tảng cửa hàng trực tuyến mini, được thiết kế để trình bày sản phẩm một cách trực quan, tối ưu cho trải nghiệm xem hàng và lựa chọn sản phẩm nhanh chóng.

---

## 📂 Cấu trúc dự án

*   **`index.html`**: Trang chủ và trang danh mục sản phẩm.
*   **`style.css`**: Hệ thống giao diện, tối ưu hóa hiển thị lưới (grid) cho sản phẩm.
*   **`script.js`**: Logic điều hướng, giỏ hàng hoặc các hiệu ứng tương tác trên web.
*   **`hinhanh*.jpg/png`**: Kho tệp hình ảnh sản phẩm đa dạng của cửa hàng.

---

## 🚀 Tính năng chính

*   **Gallery Sản phẩm**: Hiển thị danh sách sản phẩm với hình ảnh trực quan.
*   **Giao diện đáp ứng (Responsive)**: Tương thích trên nhiều thiết bị từ di động đến máy tính.
*   **Tốc độ tải nhanh**: Tối ưu hóa cấu trúc tệp giúp duyệt cửa hàng mượt mà.

## 🛠️ Hướng dẫn tích hợp
1.  **Cấu trúc dữ liệu**: Ní có thể dễ dàng thêm sản phẩm bằng cách cập nhật thẻ `<img>` trong `index.html` hoặc sửa dữ liệu trong `script.js`.
2.  **Triển khai**: 
    *   Chỉ cần upload thư mục lên các nền tảng static hosting như **GitHub Pages** hoặc **Netlify**.
    *   Không cần backend phức tạp, phù hợp cho các dự án portfolio hoặc cửa hàng tĩnh.
